CHATLY BRAIN LAB UPDATE

This update adds an original, in-app collection of eight short brain-training challenges:
- Reflex Tap
- Sequence Echo
- Number Recall
- Word Watch
- Grid Recall
- Order Memory
- Target Tap
- Typing Sprint

These are original Chatly mini-games based on broad challenge concepts. This package does not copy Human Benchmark branding, visual assets, website text, or source code.

INSTALLATION
1. Extract this ZIP.
2. Upload the contents into the root of your existing GitHub Pages repository, replacing matching website files.
3. Keep/merge the existing supabase folder. Do not nest it as supabase/supabase.
4. Commit the changes and refresh Chatly.

DATABASE
No SQL migration is needed. Scores are saved locally in the browser on the device used to play. Existing Chatly database features are unchanged.
