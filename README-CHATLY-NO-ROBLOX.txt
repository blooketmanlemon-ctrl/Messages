CHATLY — ROBLOX REMOVED
=======================

This build removes the Roblox button, hub page, saved-game UI, and related browser code.
The main screen keeps the Mini Flappy waiting game. Messaging and existing social features are retained.

INSTALLATION
------------
1. Extract this ZIP.
2. Upload the contents to the root of the existing GitHub Pages repository.
3. Replace matching website files and merge the supabase folder (do not nest it).
4. Commit and hard-refresh Chatly on each device.

DATABASE
--------
No SQL changes are required. Existing Roblox-unrelated database tables and migrations are left untouched.
Do not delete any Supabase tables or rerun old migrations for this website-only removal.
