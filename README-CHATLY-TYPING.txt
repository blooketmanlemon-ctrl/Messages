CHATLY LIVE TYPING INDICATOR UPDATE

What's new:
- Live typing indicators in private and group conversations.
- An animated three-dot bubble appears at the left below the latest message.
- Group conversations display the name(s) of people currently typing.
- The indicator disappears when the sender stops typing, sends a message, leaves the conversation, or after a short safety timeout.
- Uses Supabase Realtime Broadcast; no database table or SQL migration is required.

Install:
1. Unzip this package.
2. Replace the files in the root of your GitHub Pages repository with these files.
3. Commit the changes.
4. Hard-refresh Chatly. On iPad, close and reopen the Home Screen app.

Preserves the existing Mini Flappy home, message UI, read receipts, calls, TURN config, push function, and no-screen-sharing build.
No SQL changes, Metered changes, or Edge Function redeployment are required.
