CHATLY SETTINGS SCROLL FIX

This update fixes the settings modal by placing all settings sections inside a dedicated scroll area. The title and bottom actions remain visible while the settings list scrolls independently on desktop, iPad, and mobile.

INSTALLATION
1. Extract this ZIP.
2. Replace the files in the ROOT of your GitHub Pages repository with the files in this ZIP.
3. Commit the changes.
4. Reload Chatly. On desktop use Ctrl+Shift+R. On iPad, fully close the Home Screen app and reopen it.

No SQL migration, Metered change, or Supabase Edge Function redeployment is required.
